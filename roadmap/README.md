# Progress and roadmap

[Machine progress ledger](progress.json) · [Public progress display](../index.html)

All milestones, phases and atomic tasks use meaningful emojis and percentage values. Only completed work with verifiable evidence can reach 100%; the ledger records evidence file paths. Generated research tasks start at 0%, and compiling a task queue is not equivalent to conducting research.

**Foundation:** project charter, schema, public site, intake, gallery, color method, and verification.

**Deployment:** hosting the committed static website is a separate stage. Do not claim the published URL works without checking.

**Research:** admit named specimens only when authorized, then process all core and relevant domain-specific queues. Measure the platform, actual participant earnings and realistic earning strategies. Preserve unknowns and limitations rather than claiming exhaustive knowledge where information cannot be found.

Once a milestone is completed, routine progress reports need only show still-open work. The full evidence ledger remains here.

The ledger is hierarchical: **milestones → phases → features → atomic tasks**. Foundation percentages reflect checks that have run; full Node integration and browser rendering remain to be verified.
