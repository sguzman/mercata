# First commercial-game release cohorts: fixed clock and original project identity

**Reviewed October 27, 2026.** The official [itch.io API overview](https://itch.io/docs/api/overview) documents public new, featured and sales RSS feeds. These describe *feed items*, not a complete archival census of unique first-time positively priced game projects. The [Search & Browse guide](https://itch.io/docs/creators/getting-indexed) separates first public publication, later indexing and updates; edits should not be relabeled independent first launches.

The repository's earlier [last-7-day/last-30-day Paid filter snapshots](recent-release-filter-frames-2026.md) counted 1,057 and 3,752 results in differently cached rolling pages. The independent [2026 feed monitor](feed-volume-featured-2026.md) reported 118,017 first-seen mixed-price game pages over 152 days. None supplies a paid original-publication cohort or deduplicated commercial launch frequency. A free game later acquiring a price, an old project reappearing after a build update, or a paid DLC under an existing creator is not by itself a new commercial full-game publication.

A repeatable [offline classifier](../../site/itch-commercial-release-cohorts.mjs) now accepts owner/researcher-verified **original** project IDs, first publication timestamps, source evidence, game type and whether a positive minimum price was present at initial release, inside a predeclared UTC sampling window. A documented first publication can precede the observed feed appearance; requiring exact timestamp equality would incorrectly reject real releases. Both timestamps must be genuine calendar dates within the same declared window, the publication date cannot follow its observation, and unverified update labels are not counted as observations. It distinguishes verified first paid games, initially free games, old updates, later free-to-paid conversions and unverified sightings; duplicates are rejected. A synthetic regression proves the method, **not** a sample result.

**Population:** an explicitly sampled fixed-window set of public game project histories. **Unit:** independent game project ID with initial offer, not downloaded build or paid order. **Still missing:** authenticated initial-price history, complete eligible publisher population and synchronized cross-date windows. Without these, the real rate of new commercial releases remains unknown, and neither study task can honestly be marked fully complete.
