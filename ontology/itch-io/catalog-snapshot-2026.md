# itch.io — public game catalog counters (October 26, 2026)

Three public game-directory views were inspected at the same date. These are **browse result counts**, not game sales, unique developers, or a paid-player population.

| Filter / unit | Result count | Source |
|---|---:|---|
| All games; public filter results | 1,780,861 | [Games](https://itch.io/games) |
| Paid games; public filter results | 49,588 | [Paid Games](https://itch.io/games/store) |
| 2D-tagged games, all prices; public filter results | 428,856 | [2D Games](https://itch.io/games/tag-2d) |

The paid browse filter count is approximately **2.78%** of the default game browse result count. This describes the two **filter counters only**. It is **not a percentage of selling developers**, an estimate of revenue, a market share by spending, or a success probability. The 2D tag intersects both free and paid game listings, and a reliable paid-2D intersection was not available from the same measurement channel.

Counters can change with uploads, edits, indexing and restriction rules. No listing crawl or private account access occurred. Future trend analysis must repeat identical URLs and same filter definitions at documented dates rather than treating one snapshot as growth.

Machine data: [catalog-snapshot-2026.json](catalog-snapshot-2026.json). Further context: [platform rules and earnings limits](commercial-rules-2026.md).
