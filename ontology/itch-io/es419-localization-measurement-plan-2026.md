# Latin American Spanish localization pilot: specified, not executed

**Reviewed October 27, 2026.** This is a research-only plan for a hypothetical positively priced English-language game with a genuine Spanish (Latin America) translation. The [official creator quality rules](https://itch.io/docs/creators/quality-guidelines) prohibit selecting a language the game does not support. The [indexing guide](https://itch.io/docs/creators/getting-indexed) explains how accurate language metadata affects eligible browsing, not how many purchases result.

The existing [es-419, Paid, 2D Top Sellers public directory](https://itch.io/games/top-sellers/lang-es-419/store/tag-2d) showed **174 listing results** in its cached observation. It is a supply filter, **not** confirmed local buyer demand or a country-revenue estimate.

**Target:** es-419, starting from an English game with permission to change and test it. First inventory translatable strings and source words, then log nonoverlapping minutes separately for UI, dialogue, game description, captions, proofreading, font/overflow adjustments and QA. Hours equal the sum of recorded unique task minutes divided by 60. No actual game, translation sessions, hourly rate or real translation hours have been supplied, so all remain unknown.

**Conversion design:** If an authorized experiment becomes feasible, compare the same positive-price game build and price under English and es-419 content with matched release age, visit/referral source, country/device mix and equal **7/30/90-day** observation periods. Track page views, browser plays, checkout attempts, completed paid orders, refunds, actual merchant proceeds and labor/cash costs **separately**. Page-view event ratios cannot become unique-buyer conversion probabilities. Without a controlled assignment, results would only be descriptive.

**Accepted task scope:** the existing task asked for a *plan* defining a language, translation-hour accounting and paid conversion measurement. Those are specified here. It does **not** claim translations completed, a merchant release, costs, conversion uplift or positive ROI. [Machine plan](es419-localization-measurement-plan-2026.json).
