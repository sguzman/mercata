# One first paid 2D game: early zero-sale and discovery snapshot

**Reviewed October 27, 2026.** The creator of [*Nobody Leaves*](https://pallavi-sahoo.itch.io/nobody-leaves), a pixel-art 2D puzzle/horror escape-room game, [asked for feedback on October 25](https://itch.io/t/7220162/nobody-leaves-700-impressions-under-1-click-0-sales-what-makes-you-skip-it). This is one self-selecting **two-person team** reporting on its first game, not an audited or representative paid-publisher cohort.

| Observation | Publicly reported value | Unit / limitations |
|---|---|---|
| Paid full-game offer | **$1.99 introductory**, normally **$3.99** | Minimum checkout price for downloadable builds; no actual buyer payment seen |
| Free browser preview | **First seven rooms** | Playable content, not a paid order |
| itch.io listings shown | **About 700** | Browse **impression events** described as 'this week'; not unique buyers |
| Listing click-through | **Under 1%** | Click share, not checkout or sales conversion |
| Purchases by forum post | **0 (creator-reported)** | Dated October 25; not an audited transaction export or lifetime outcome |

The public product page displays a release time of **October 24, 2026, 14:00 UTC**, while the forum post is timestamped **October 25, 2026, 13:14 UTC** and describes the game as having launched "two days ago." These clocks conflict if interpreted as the same first-public event. The "this week" impression interval is also not bounded to the release timestamp. **No exact common observation horizon can be reconstructed** without merchant analytics.

This case is unusually close to Mercata's target because it identifies a concrete new **paid-minimum 2D game**, a free demo attached to the premium offer, and a creator-reported zero-sale checkpoint. Nevertheless, a listing impression, listing click, product page visit, browser play, begun checkout, and successfully retained paid order are six different events. Fewer than 1% of approximately 700 impressions does **not** support a precise number of clicks or any estimate of unique purchase probability.

The author sought page and demo feedback; that discussion cannot establish why no sales were reported. The listing does not prove regional payment approval, and the early price is not an actual sale price because no transaction was observed. A later purchase could occur; this is **not** a zero-lifetime-sales declaration.

**Research consequence:** this strengthens the original paid-purchase-demand task with one bounded first-game outcome, without declaring observed platform demand, average income, or the fraction of all paid game releases that fail to sell.
