# Marketplace dossiers

There are **26 admitted but unresearched marketplace dossiers**, all conforming to the [public specimen schema](../ontology/specimen.schema.json). Every dossier begins with no claims, earnings statistics, sources, observations, experiments, or revenue findings. The [gallery](../gallery/README.md) contains the public names and links.

Do not confuse an empty field with a zero fee or a zero income. The platform identity, website, domain and unique color are intake metadata; economic claims need later sourced research.
