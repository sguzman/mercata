# Marketplace gallery

The public [website](../index.html) renders this collection from [index.json](index.json). No marketplace specimen has been admitted, studied, or published. The empty gallery is intentional; synthetic documentation examples do not count as records.

Each admitted specimen will link to its versioned dossier in `specimens/`, its own research task queue in `queues/`, admission date and unique OKLab-derived color. Its status must not be confused with evidence quality or earning potential.
