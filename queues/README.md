# Marketplace research queues

There are **26 separate JSON research queues**, one per approved marketplace. Each has 12 core queues and one appropriate specialist queue: 84 atomic tasks per specimen, **2,184 tasks total**.

All tasks begin at 0% and have explicit acceptance conditions, weights, statuses and empty evidence references. They are questions to investigate, not assertions about the platforms. See the [pipeline](../pipeline/README.md) and [gallery](../gallery/README.md).
