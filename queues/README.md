# Marketplace research queues

Mercata has **26 specimen queue files** containing **437 workstreams and 3,064 atomic tasks**. Each platform has 12 core queues and its domain specialist queue (84 tasks). Eleven social or creator-community platforms have nine additional audience research queues (80 tasks each), bringing those specimens to 164 tasks in 22 queues.

Every task remains pending at 0% until supported by documented acceptance evidence. Queue creation is not a verified finding about the platform.
